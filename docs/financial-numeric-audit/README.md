## 原始版本與時間證據的界線

本次已證明上述數值與「公司官網同一期中文合併財報」吻合，狀態是 `OFFICIAL_ISSUER_PDF_VALUES_MATCHED_ORIGINAL_VERSION_LINK_PENDING`。每項保留原封存 MOPS 檔名與上傳時間，但尚未證明公司官網 PDF 與當時 MOPS 原檔逐位元組相同，前期文件的原始 MOPS 版本鏈也未補齊。因此不把任何一組升格為完整歷史 PIT 驗證，139 組的這一層仍待串證；這與「數值已吻合 2 組」是不同的計數。

九個日期各有 1/80 家取得上述公司 PDF 數值覆蓋，其餘各 79 家待查；不能把重複的九個公司日當九家。更不能將一家的成果推廣成全池通過。
